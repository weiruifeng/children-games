# 汉字课程内容包

`candidate-ledger.ts` 保存1294项候选的稳定读音身份、分类、字义项、语境、资料证据以及分开的文本/拆分/提示/音频审核记录。`level-ledger.ts` 保存239个稳定关卡身份及原草案编号；它们是正式运行时数据，不依赖本机目录或 `.workbench`。

来源为 [内容收录资料](../../../../docs/specs/pinyin-garden/content-inventory/README.md)，保留其中来源、分类政策和 [字音资料许可](../../../../docs/specs/pinyin-garden/content-inventory/pinyin-data-LICENSE.txt)。`sourceRef` 可逐项回溯原始清单；教学清单之外的扩展项保留空 `sourceId`，不冒充规范清单编号。

本次文本核对13个常用字补充读音（吧、臂、卜、瘩、啦、拎、蕊、啥、裳、匙、嗦、着、子），逐项写定限定语境。录音全部仍为待听审，没有批量批准。基础6关沿用已有符号与标调内容。软件可以承载全部分类；当前发布仅是明确标注的试运行子集。

修改内容时：

1. 逐字/义项补全语境与来源，更新相应审核人、日期、意见；不能只改顶层状态。
2. 主线音频必须有独立身份/读音审校记录和原文件SHA-256；补充无录音不得绑定同名基础音。发布音频还需接入现有manifest及public资源。
3. 不重新排列稳定关卡ID。迁类保留readingId和原sourceId，历史成绩不直接赠送新关。
4. 执行 `npm run validate:garden-content`、花园测试、类型检查及构建；内容变更必须检查进行中快照的答案校验，必要时升级内容包版本与迁移规则。
5. 报告已发布、待审、待补与排除的真实范围。当前待审项不被组题器选取。

运行时快照保存选项、题目顺序、出场队列及文本/拼音/拆分校验值；题库变更导致校验不一致时拒绝恢复并保留原始备份，不静默换题。
