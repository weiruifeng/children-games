## 运行与发布

- 本地：`npm run dev:pinyin`。平板同 Wi-Fi：`npm run dev -w web -- --host 0.0.0.0 --port 5174`。
- 校验：`npm run type-check`、`npm test -w web`、`npm run build`。
- 生产预览：`npm run preview -w web -- --host 127.0.0.1 --port 4174`，直接访问并刷新 `/experiments/pinyin-garden/`。
- 静态产物为 `web/dist`，入口依赖站点根下 `/assets/`。当前只验证根路径部署，不支持任意子目录 base。部署时保留目录结构，不将所有资源请求重写成 HTML。
- 不需要启动 server、MySQL、LLM，不需要密钥。现有主站和恐龙游戏仍单独保留。
- 实际线上托管尚未指定，未执行外部发布。宿主应提供 HTTPS 和正确的 PNG/WAV/JS MIME。HTML 与非哈希素材使用短缓存或验证缓存，哈希 JS/CSS 可长期缓存。回退时整体替换为上一构建版本，不混用旧代码与新资源。
- 游戏没有 Service Worker 或完整离线缓存保证。已解码素材可在当前会话继续用；未加载图片失败会暂停并显示重试。

## 内容与复习

`shared/src/pinyin-garden/content.ts` 是首发 30 个单字目标、12 个词与五关配置的运行来源。新增内容需同时维护教学拆分、合法音节与关卡引用，运行拼音/战斗测试。当前内容范围不是“小学初中全部字词”完成声明。

第五关通关后开放字词复习，基于已有尝试选取最多 10 个字词：近期薄弱 5、到期 3、已学随机 2。分组互斥；不足时从其他组补足，不引入未出现内容。词语任一音节需要帮助或未完成时仍归入薄弱。复习沿用第五关三路战斗及已解锁伙伴，独立记录最好成绩，不修改正式关卡星星、解锁和奖励。

记录保留正确、帮助、重复、时间，以及新增记录的关卡、战斗/复习来源、是否失败后重试。旧记录缺失的来源不做推断。收藏展示次数和独立完成发生的天数，不把尝试次数直接解释成掌握程度。

## 存档

防守使用三颗爱心：每只墨团到达家园扣一颗，归零立即本波失败，可恢复波初快照重试；答错本身不扣心。已取消风铃自动救场，旧存档的 `rescues` 字段仅用于兼容，不再提供保护。漏怪的波次显示“这一波结束了”及漏怪数量，全部挡住才显示“守住啦”。第一关第一波只有两只墨团，因此完全不操作会剩一颗爱心进入第二波，第三次漏怪时失败。

IndexedDB `pinyin-garden` / `profiles`，三个独立槽位。数据版本 `1`、内容包 `garden-1`；新增 `reviewPool`、`retryCount` 和尝试来源为可选字段，兼容已有备份。

当前进度 `checkpoint` 与波初 `waveStart` 分开保存；失败重试保留尝试历史。音乐与音效音量随花园保存，顶栏静音仅本次页面会话有效。页面切后台暂停，回来显式继续。

损坏槽位单独隔离，其他槽位仍可进入；修复入口先下载三个槽位的原始备份，用户确认后仅清空选中槽位。写入以 IndexedDB transaction 完成为准，失败显示提示，不宣称已经保存。导入前校验内容，再确认覆盖；等待未结束的写入，防止旧写入覆盖新备份。

存档按浏览器 origin 隔离，IP、端口、域名变化或隐私浏览都会影响可见存档。换地址前主动导出，再在新地址导入。

## 美术与音频

- `web/public/assets/pinyin-garden/characters/`：七个原创角色 PNG。
- `backgrounds/`：原白天背景与新晚霞背景；晚霞亦用于基地。
- `props/`：种子、松果、露珠、风铃、拱门、两级藤盾损伤完整外观、纸壳破甲层。
- `provenance.json`：实际生成工具、提示词、来源与预览状态，不含本机路径或密钥。
- `assets/manifest.ts` 负责图片映射，`EntityViews` 负责表现。图片先加载再进入模拟，缺失时暂停并提供重试。
- 攻击、受击、破甲、退场等由模拟事实/事件驱动，动画不结算伤害。场景使用稳定地块定位，字牌不跟着墨团弹跳。
- `audio-manifest.json`：4 首音乐、38 类共 50 个音效。程序合成原始生成器在 `scripts/generate-garden-audio.py`。首次手势启用音频，限制重复及同时播放；音乐总混音为设置值的 50%，碰撞时临时再降至 40% 并恢复。
- 学习语音仍全部为空，不生成朗读、不调用付费 TTS。将来补音频需按已有条目 `audioId` 扩展，不能把音效当成标准读音。

## 页面路由、刷新恢复与铲除

使用 hash 路由，无需静态服务器配置路径回退：`#/gardens`、`#/garden/1/home`、`#/garden/1/battle/3`、`#/garden/1/review`、`#/garden/1/collection`、`#/garden/1/settings`。URL 中花园编号为 1–3。浏览器前进/后退恢复对应花园；战斗链接只恢复匹配的已有检查点，没有匹配进度时回到花园首页，不自动覆盖存档或开启锁定关卡。

战斗操作后立即保存，运行期间每秒保存，页面隐藏与离开时也保存。同步 localStorage 恢复记录先落地，再串行写入 IndexedDB；旧写入完成不会清掉较新的恢复记录。刷新后保留伙伴、资源、共享弹药和未完成拼音草稿，进行中的战斗先暂停。波开始快照单独保留，用于失败重试；旧版不含草稿的存档继续兼容。路由和保存均在前端实现，不需要服务端。

铲子按钮使用手绘道具图标，显示「铲除 / 挖走伙伴」，选中后提示「点一下要挖走的伙伴」，各伙伴标出具体返还露珠。费用规则不常驻在操作按钮上。铲除一次自动退出工具；100/50/50/150 的伙伴分别返还 50/25/25/75，重新种植仍按原价收费。

iPad 横屏工坊统一预留四部件空间，切换二拼和三拼不再改变目标区、弹药区和战场的尺寸或位置。浏览器验收覆盖 1024×768 横屏、768×1024 竖屏，h/u/a/一声可完成并在刷新后保留共享弹药。

正式游戏沿用原有 Phaser 战斗、音频、五关内容、星级奖励、三个存档与 hash 路由；`web/public/design/pinyin-garden-review.html` 仅作为独立评审稿保留，不被正式实现引用。

- 横屏伙伴栏两列；iPad 竖屏下置，战场按自身比例显示。卡片、拖动与场上角色共用屏幕像素尺寸（常规 iPad 64px，大屏 72px，手机 44px），拖动时仅显示一份角色和格子高亮。真实 PNG 透明留白保持一致，不扭曲素材比例。
- 轻点伙伴卡查看用途，拖动才种植。露珠不足或冷却显示原因，并允许点击获得说明；未开始、暂停、提示期间禁止种植。铲除优先于露珠与敌人点击，完成一次自动退出；开始拖动伙伴会退出铲除模式。
- 露珠价格、余额、掉落和收集动画使用同一道具素材。收集目标至少为 52 CSS 像素直径；手动和自动收集都展示 +数值，并飞向余额（减少动态时只显示数字提示）。原有真实产出时间与 8 秒自动收集规则保持。
- 三拼与二拼预留同一组部件列，声调使用居中的图形标记，空槽用圆点；错误提示可见。汉字在弹药栏始终保留，勾选标识本波已准备，场上需要的弹药使用虚线边框。词语高亮当前字并保留已完成音节。
- 拼音问号改为明确的“提示”，没有可提示任务时保留位置但不展示无效按钮；右上角书本仅用于伙伴图鉴。提示会暂停，支持看答案、保留部件/缩小选字范围、进一步示范。学习语音仍未启用。
- 同一音节首次完整错误记录一次，持续修改不会重复增加错误尝试，答对记录成功；跨弹药切换、刷新保存保持该纠错轮次。评分仍区分独立完成与纠错/提示后完成。

验收使用独立浏览器上下文，不替换真实玩家存档。涵盖三行同时发射、触屏拖动、露珠重叠时铲除、真实产露珠与 +25 收集动画、刷新暂停恢复、首次引导及横竖屏/手机宽度无横向溢出。临时截图在 `.workbench/20261106-garden-redesign/`，可在复核后清理。
