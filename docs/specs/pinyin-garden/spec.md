## 2. 目标与不变范围

目标：用汉字或明确的词语语境练习普通话拼音组合；系统安排合法音节及有效声调，避免只记题序或按钮位置。对较少见读音保留可选拓展入口，不为凑覆盖率强塞生僻字进主线。

保留以下现有行为及数值，以实施开始时的运行代码和回归用例为基线：

- 原角色、美术、音乐音效、种植拖放和点击备用操作，原3×6战场、五档路线/刷怪配置。
- 每小关三波；手动开始后进入12秒布置宽限；波间等待玩家开始，不要求先完成答题才能开战。
- 露珠、费用、生产、铲除退款、伙伴冷却、护盾、三颗爱心及现有漏怪判定。不得恢复历史风铃自动救援。
- 正确完成即解锁本波共享弹药；兼容射手独立持续攻击，换题或点选部件不暂停、不减速、不等待音频。
- 不恢复手动提交、手动发射、有限弹夹或逐射手装弹。帮助/暂停/后台冻结全场，现有慢速开关仍统一影响模拟。
- 普通错误不直接扣爱心/露珠；敌人仍正常推进。失败重试、当前进度恢复和波初重试继续分别处理。

不新增朗读识别、听音必答、麦克风、实时AI出题、强制语音服务或新的美术制作。此次也不授权外部部署。

### 3.2 常用字和读音筛选

沿用 [常用字规则](content-inventory/common-character-policy.json)：一级3500常用字是字集门槛，具体读音还需常用读音映射、频率字音词典或教学字音与语境交叉证据。数据匹配仅是初筛，不等于低龄熟悉度和人工审音。

- 在完整候选库中搜索合格常用字，不只检查旧版每音前4个候选。
- 同一读音有合格常用字：保留该读音，普通候选只用合格字；摘出的字放 `challengeCandidates`。
- 没有合格常用字：整个读音移至挑战。挑战内有音频与无音频分别标注。
- 主线和补充的题干、换字、复习、汉字干扰项均不得引用挑战字。拼音部件干扰项还必须通过课程技能范围校验。
- 自选挑战可复习同音的非常用字，不重复计算新的读音覆盖，也不能成为主线完成条件。
- `miǎn`保留免/勉而移出丏/偭；`ruí`等无合格普通承载字的读音整项挑战。具体名单以审校后数据为准。

### 3.3 发布审核

每个读音、承载字/义项、语境、教学拆分、提示文案、音频分别有 `draft / reviewed / excluded` 状态、来源和审核记录；不得沿用旧类型默认将所有条目标为 `reviewed`。

正式任务必须满足：读音合法、承载字匹配、必要语境明确、教学前置完整、答案唯一或有明确合法答案集合、兼容现有伙伴。词语中的非目标字只作语境时不要求拼写；变为整词题必须检查每个音节。

文字发布与音频发布分别判定。主线的关联录音必须完成身份/读音核对后才能绑定播放；音频待审不阻止文字练习，也不冒充“缺录音”更改分类。录音请求在游玩时失败仅降级播放，不改变课程或成绩。

文字可采用可复现的 `source-verified` 资料验证：逐项核对字音映射、常用字与本读音证据、多音字语境、拼式和课程前置；与旧有人工 `reviewed` 状态严格分开。验证来源、被拒候选和排除原因存入 text-audit.json，不批量伪造人工审核。语气字无法仅凭字形唯一决定声调的，采用显式示范练习，答案可见且始终计辅助完成。此类示范不声称考核辨音或独立拼写。

暂未通过的项目留在覆盖清单中，展示为待审/待补，不静默删除。允许明确标为试运行的审核子集用于验证，但不能据此宣布全量完成。没有合法候选的小关不得出空题；入口显示待完善原因，不显示成学习进度锁。

## 4. 课程开放与推荐

- 所有已发布字母训练、普通冒险和奇遇关卡均可尝试；不以星星、前置通关或家长课堂进度硬锁课程。
- 首页是一屏冒险场景：当前目的地、伙伴、地图节点、出发/继续守护，以及地图/伙伴/收藏入口。完整地区和任务列表放入每页6项的地图弹层；学习范围以地区副标题和出发卡片轻量提示，不在首页堆课程目录。
- 新玩家推荐基础入门；家长选择“课堂学到哪里”只改变推荐与默认复习范围，不限制手动访问其他已发布课。
- 提前进入后续课给简短前置知识示范和提示入口，不要求补打前置关。示范不新增答题门槛，也不自动认定孩子已学会所有前置内容。
- “允许出题范围”来自所选课程的显式先修规则与当前波新增规则；“孩子实际练过”来自记录。这两个集合必须分开。
- 五档战场对新旧存档全部开放，对应伙伴按所选战场配齐。战场难度与知识范围独立，不自动升档；战场星星继续用于成绩与装饰，不锁入口。切换档位后从新一局开始。
- 最低战场不得因缺伙伴而卡住单字课程。整词/卷轴只在有合格词题及兼容伙伴的组合出现，否则用兼容单字敌人，不强制新兵种。
- 成绩只标未尝试、尝试过、通关、独立完成记录；挑战自选，跳过挑战不阻碍主线。

## 5. 汉字任务与帮助

### 5.1 展示与作答

基础认识允许字母匹配和带调韵母示范；普通挑战以汉字为目标。多音字用词语或短句限定读音，目标字明确高亮，不靠孩子猜出题人意图。

默认隐藏完整拼音。敌人字牌、工坊、未解锁弹药栏、候选提示、悬浮提示及辅助读屏标签都不得提前泄露完整答案；目标图片不得烘焙拼音。完成后可显示正确拼音。

照现有交互点击声母/介音/韵母/整体卡/声调；部件齐全自动判题，正确立即装弹，不自动切题。错误保留选择并允许修正；错误草稿不得作为正确读音播放。

整体认读音节使用合法整体卡，不伪造声母拆分；无声母音节不提供假声母。词题按原机制逐音节完成，全部正确才解锁整词弹药。

### 5.2 示范与独立证据

- 开波前与波间只显示本波汉字/字母卡，不提供整波答案展开。遇到不会的当前卡片，用“教我拼”暂停并逐个展示部件、声调和完整拼音，支持重播与返回自己操作。
- 同一对局/波次中已展示某目标答案，后续关闭提示后答对仍为辅助完成。首次示范、提示级别与播放记录分别保存。
- 后续对局可隐藏答案独立挑战。来自同一读音弹药共享或同波换同音字的自动完成不能新增独立证据。
- 提示动画依次突出部件、声调和完整拼音；主动打开帮助暂停，普通点字发音不暂停。提示仅标记当前目标，帮助不取消守护奖励、不阻止装弹；独立作答证据单独记录。
- 按钮位置和题序记忆不等于学习；独立记录必须满足首次完整提交正确、未揭示答案、非重试重复任务。

### 5.3 声调、轻声与特殊拼式

数据使用 `tone: 1|2|3|4|5`，5表示轻声；基础符号用独立任务类型，不用0同时表示“未选择”和“轻声”。运行时未选择用 `null`。

轻声任务提供明确“轻声”选项与无调号显示，不能把未选声调自动判成轻声。只在轻声课程/已介绍规则中出现。字典标调、自然语流变调分开，不把点读中的变调反写成答案。

保留显式拼式白名单和Unicode正规化；覆盖ü省点、n/l保留ü、三拼、iu/ui缩写与标调、y/w、整体认读。ḿ/ń等特殊成音节读音仅经单独设计和审校后进入挑战，不强套普通声母+韵母校验。

## 6. 组题与共享弹药契约

每小关至多6个新读音目标，每波至多2个新目标，预留至多2个复习位；容量是初值，审校后可拆合。每波知识架继续最多6项，新增目标优先于随机复习。

组题顺序固定：

1. 仅取当前内容包已审核条目，按所选内容类别、章节、当前波规则和伙伴兼容性过滤。
2. 按本关教学目标安排未练读音；已练时优先薄弱/待复习读音，再选熟悉内容。不用纯随机代替覆盖排程。
3. 在当前读音的合格候选字中轮换，降低上一局刚出现字的优先级；仅有一个合格字时允许重复，不用生僻字凑新鲜感。
4. 复习只来自孩子实际练过且符合当前范围的项目；补充/挑战记录不能自动进入主线。集合不足就少出复习或重复合格内容，不扩大范围。
5. 非声调部件初值为正确项加最多2个不同干扰项；候选不足允许2选1或引导操作，但一选一不作为独立完成证据。正确项必须存在，不能制造无解题。声调按已介绍的集合展示。
6. 生成整局三波的题目、选项、示范状态和出场覆盖队列，保存到对局快照。用独立的学习随机种子，不跟随战斗刷怪/攻击随机数变化。

同一对局换题、暂停、刷新、重试不得重新抽题或重排选项；主动“再玩一局”生成新 `runId`，才可轮换。候选变更不得改变进行中的答案。

每波新目标至少各有一次可操作任务及对应敌人出场；剩余敌人可重复使用本波合法目标。三波通关不能作为全部目标已作答的证明，因为范围伤害可能击杀未作答目标；未实际完成的项仍是未练，下次优先安排，不因漏练阻止本次战斗通关。

同波同一读音只选择一个承载字，避免弹药共享让第二个同音字“自动答对”。弹药以完整带调读音签名共享；任务和学习记录以字/义项实例区分。挑战中的同音换字同样不能刷独立完成。纯符号弹药与带调音节弹药保持不同签名。

若可发布内容不足：在开局前显示内容待完善，不抽未审条目。若内容包或存档已损坏：拒绝该检查点并保留备份，不进入无解战斗。

## 7. 点读与音频

沿用现有 `pronunciation` 音频通道与本地素材，来源 `/Users/weiruifeng/ai/PinYinSound` 只用于开发导入；正式包使用相对URL，不要求玩家机器存在该目录。

- 点击汉字/喇叭读目标；点击部件可播已审核基础音；最后一块正确时优先播完整音节。播放不等待、不改变判题与战斗时间。
- 普通点读记录为 `audioUsed`，不等于揭示书面答案，不因此取消独立拼写记录；此记录仍不证明听辨或口头发音能力。
- 缺录音的补充/挑战隐藏播放按钮，标明暂无发音，文字帮助可用。基础教学音不得冒充同名轻声或完整音节。
- 保留独立音量、静音、背景音乐压低、短时间误触去重、后点替换前点及异步过期请求隔离。
- 换页/后台/主动暂停取消待播；帮助内允许显式点示范。播放失败轻提示，继续作答与攻防。
- 有效词语语境只播放目标字，除非另有审核后的完整词语播放定义。逐音节音频串联需标记，不伪称自然连读。
- 按需加载，不首屏下载整个1420文件库。人工听审与文件存在/解码验证分别记录。

| Coverage | 完整审定目标、已发布、待审/待补/排除及原因；每个分组单独计数 |

阅读键保持既有1294项身份。`Mxx/Axx/Cxx`只是草案编排号；发布后 `levelId` 稳定，不因插入关卡或换字重排。主线移到挑战时保留readingId和历史，变更类别有内容版本，不能复制成“新知识”。

基础符号、带调音节、字义项与整词使用不同实体/签名，避免基础a与ā、轻声ma相混。同一任务实例只计一次正确奖励；新射手、换同音敌人、范围伤害不新增学习奖励。

通关、星星、装饰和战场成长沿用现有机制，但课程不由星星解锁。课程成绩与战场成绩分别保存；分组移动后历史星星保留，不直接算作新关通关。最佳分按内容包、关卡、战场和计分版本隔离。

家长页面分别展示：已发布覆盖、待完善缺口、实际尝试、提示完成、独立完成；基础认识不算带调汉字覆盖。第一轮不用“掌握所有读音”标签。

“多次独立完成”初始标准：同一读音最近3次合格独立挑战均首次正确，来自3个不同对局且跨至少2个自然日；有至少2个审核候选字时需覆盖2个字，无第二个候选时不强塞新字。失败后的修正/同局重试不能补造首次正确。标准是产品记录规则，可通过试玩调整，不作为教育测评结论，也不用于锁关。

旧版始终可见样板的结果只保留为“有样板操作”历史，不迁移成新版独立拼写证据。仅听过、看过或自动共享弹药不能标成作答完成。

## 9. 存档与版本迁移

改造前为Profile v2、内容包garden-curriculum-2、IndexedDB版本2。现采用Profile v3与garden-character-3.1；保留旧数据存储，数据库版本3新增 `profilesV3` 与按来源版本区分的迁移归档。迁移规则在编码前用fixture固定。

- 迁移v1/v2原始记录，保留名字、设置、战场解锁、伙伴权益、旧星星/最好成绩、历史尝试和旧检查点归档。
- 旧数字 `lessonId` 不直接解释为新的levelId；使用显式迁移表将14课映射到章节推荐位置，不伪造新小关通关。
- 旧课堂上限改成推荐偏好，`lessonUnlocked/lessonLimit` 不继续挡住课程入口。
- 旧活动对局与旧波初快照成对归档，不能把旧抽题硬套新字库；提示“课程已更新，旧成绩保留”，从推荐入口重新开局。

- 不认识的内容包或已撤回条目拒绝活动检查点，保留可导出的原始数据与历史，不静默把错误数据当新档。

## 10. 验收标准

| 编号 | 必须通过的行为 |
|---|---|
| AC01 | 全部已发布课程可直接进入，家长进度只影响推荐；待审关显示内容状态而非学习锁 |
| AC02 | 普通题默认只显示目标汉字/语境；字牌、弹药栏、辅助标签不提前泄露完整答案 |
| AC03 | 示例/帮助后答对为辅助完成；关闭帮助、刷新、重试不能转成独立 |
| AC04 | 主线/常用字补充题干、换字、复习、干扰项均不混入挑战字；全量扫描有证据 |
| AC05 | 主线有合格音频；补充缺音频无坏按钮；挑战有无音频均可玩，临时播放失败不阻塞 |
| AC06 | 单韵母、双拼、三拼、整体卡、ü规则、轻声各有正误路径；未知组合明确拒绝 |
| AC07 | 新目标在对应波可操作且会出场，跨局优先补未练；随机样本覆盖不足时测试失败 |
| AC08 | 同局刷新/重试题目和选项稳定，新局可轮换；战斗随机数不导致学习选项跳动 |
| AC09 | 同音共享、多射手、范围伤害不能刷独立证据；不同字与同一读音的记录可追溯 |
| AC10 | 保留实时种植/资源/攻击/三波节奏；点选和点读时模拟持续，帮助/后台才冻结 |
| AC11 | 各已发布小关与可用战场/伙伴组合可完成，不生成无兼容武器的词语/卷轴目标 |
| AC12 | v1/v2/v3导入、正常迁移、坏槽隔离、配额失败、多页写入、当前恢复和波初重试通过 |
| AC13 | 覆盖报告区分候选/发布/待审/挑战/实际作答；无静默删项或伪造掌握结论 |
| AC14 | 1024×768、768×1024、390×844布局和触控通过；候选点击区≥44px，长音节和语境可读 |
| AC15 | 类型、相关及全套测试、生产构建、生产入口刷新与资源加载通过，既有其他游戏入口无回归 |

必须记录实际命令、结果与人工审核范围。浏览器触控模拟不冒充实体iPad；全量解码不冒充录音听审；试运行子集不冒充全量上线。实体设备与儿童试玩单列真实状态。

- 原始 `level-ledger.ts` 及音频分流台账留存为来源与迁移证据；正式运行时使用 `adventure-levels.ts`。常用字原主线和补充合并为普通冒险，不因缺录音拆成孤立小关。覆盖报告仍可追溯原音频分类。
