## 1. 产品目标与范围

面向一位约 5 岁、希望挑战更丰富汉字和拼音组合的孩子。内容难度按能力选择，不按年龄或年级锁定。借鉴多路线种植塔防，使用原创角色外观与花园世界。

核心循环（共享弹药版）：拖伙伴布阵 → 点选汉字/词语 → 拼好读音 → 本波全队共享 → 多个射手独立持续攻击 → 一边学习一边布阵 → 下一波重新补充弹药。

### 1.1 首版必须包含

- 3 行 × 6 列战场，4 种植物，3 种敌人，2 张背景。
- 1 个章节、5 个关卡，每关 3 波；知识复习可重玩。
- 单音节组合、三拼组合、双字词串联、给拼音选汉字四类操作。
- 一至四声独立选择；完整拼音和声调显示正确。
- 候选部件、三级帮助、慢动作装弹、策略布阵。
- 关卡通关、三项星星成就、确定性植物解锁、分数与个人纪录。
- 角色动作、战斗特效、背景音乐、战斗及 UI 音效。
- 本地多存档、波次检查点、导入导出、暂停与后台自动暂停。
- 首发题库经人工审阅；引擎校验合法音节、答案及前置知识。

### 1.2 后续扩展

学习语音、听音选弹、朗读识别、更多章节、全量 3500 常用字及扩展词库、跨设备同步、手机专用布局。首版不将这些作为交付前提。

完整首版指上面的产品范围完整，不指一次录完全部语音或整理完小学至初中所有词语。不做实时 AI 出题、随机宝箱、签到惩罚、付费数值提升和公共排名。

### 1.3 原创世界观与线上发布约束

暂定名仍为《拼音花园保卫战》，正式发布前检查名称与图标是否存在冲突，不将暂定名视为已完成商标检索。故事：墨团怪把字词带进花园，孩子帮助植物伙伴组装拼音种子，化解墨团、守护花园。战斗失败表现为墨迹闯入，不表现为伤害人类。

## 2. 页面、输入与可读性

### 2.1 页面流

存档选择 → 花园基地 → 章节/关卡 → 植物准备 → 战斗 → 结算 → 下一关或基地。

基地包含：开始/继续、植物收藏、知识收藏、装饰、设置、家长详情。知识收藏首版展示字、拼音、例词与完成记录；无音频时不出现喇叭。

### 2.2 横屏布局

战斗页占满 `100dvh`，平板横屏与电脑使用上弹药台、下战场，不依赖页面滚动或自动滚屏。战场逻辑画布 1280×640，等比例缩放并安全留边。

- 顶部紧凑导航与状态栏：关卡、波次、露珠、爱心、得分、暂停。
- 战场左侧：伙伴卡和移植工具；下方主要空间：战场；底部保留开始波次、慢速和离开。
- 顶部固定弹药台：当前字词、固定拼音槽、声母/介音/韵母/声调候选、帮助与全队弹药栏。不显示装弹确认或发射按钮。
- 战场仍为 3 行 × 6 列，逻辑坐标 x=220–1120、y=170–590，敌人从右进场。
- 窄竖屏仍使用上弹药台、下战场，候选卡折行；极小视口允许弹药台内部滚动兜底，不裁掉功能。平板横屏是主要验收尺寸。
- 字牌使用独立 UI 层，不烘焙进角色；跟随水平位置，垂直轻度平滑，避免走路抖动。
- 敌人 72–100 逻辑像素高；字牌字高约 32–40；拼音约 28–36；触控区在实际显示尺寸下至少 44 CSS px，优先 48。
- 相邻字牌重叠时错层并连线指向敌人；候选区开启时最多 6 个声母、6 个韵母、4 个声调按钮，分步展示，不一次铺满全部字母。
- 显示字体必须覆盖 ü、四声组合字形；拼音保持小写，不能转成全大写。颜色不能作为唯一正确性线索。

### 2.3 操作

伙伴卡拖到空地种植，落点预览与实际判定使用同一个拖拽图形中心；点卡片后点空地保留为备用。拼音采用大卡片轻点选择，不再逐片拖到射手或拖完整子弹发射。

上方弹药台显示当前知识任务、固定拼音槽、候选卡和共享弹药栏。点场上敌人或弹药栏即可换题；各题草稿保留。修改声调只替换声调，答错保留所有选择。拼对后当前任务保持可见，不自动跳题。

弹药栏列出关卡知识池；在场敌人对应弹药标记待补充，已解锁项显示读音与 ∞。所有在场及之后种下的兼容射手共用本波弹药。没有可用射手时仍可学习并储存弹药。

## 3. 战斗与学习契约

### 3.1 共享与命中

- 解锁按完整带调音节签名共享。不同路线可同时使用相同弹药；同一行两个射手拥有各自的冷却和伤害输出，不重复收费、不重复答题。
- 每个射手自动选择同行前方最近且已有对应弹药的活敌人。弹弓手攻击单字目标；投石手支持单字和完整词语。
- 学习任务与实体生命周期解耦：目标退场、伙伴被移除或换题都不取消知识草稿，也不撤销弹药。
- 飞行弹只匹配对应签名；原目标消失后寻找同行匹配目标，找不到则消散。
- 松果主目标伤害与范围伤害保持；附带击杀和风铃救援不记为知识完成。
- 下一波开始清空本波弹药、草稿和残留投射物；保留伙伴及资源。波间由孩子点击开始，不强制倒计时。

### 3.2 学习与解锁

1. 选汉字/词语，或首次遇敌时显示一个待补充任务。
2. 点选声母、介音（如需）、韵母或整体音节，以及一至四声。
3. 必需部件齐全后自动校验；错误保留所有选择，不扣爱心或露珠。再次点击同一已选部件不重复计一次错误。
4. 正确后解锁该签名，全队本波不限次数使用。显示“全队可用”，射手各自自动攻击，不需要发射按钮。
5. 双字词逐音节完成；必须全部正确才解锁，不让第一个音节提前造成攻击。
6. 拼音选字模式显示完整拼音与候选字；选择正确后解锁对应弹药。

任务奖励由波次、签名和音节索引唯一确定；同波重复选择、增加射手、同音敌人增多不会重复产生学习分。新波允许再次学习。同一波重试的尝试日志保留并标记重复。

### 3.3 错误、帮助和时间

- 错误保留有效部分，仅指出本次需要修改的槽；不直接扣露珠或爱心。
- 非法音节明确提示“这组还不能拼成音节”，不编造读音。
- 三级帮助：显示完整目标拼音 → 突出正确部件并减少候选 → 动画演示后让孩子再完成。
- 一旦展示答案或突出正确候选，本任务记为 assisted。未来的纯重听不算揭示答案。
- 学习期间战斗保持正常速度，不降低其他伙伴攻击效率。帮助和暂停时全场 0 倍；设置“慢速战斗”时全场 0.7 倍。
- 移动、攻击、生产、冷却、刷怪统一使用模拟时间；UI 动画使用实际时间。慢动作不能只延缓敌人却加速刷资源。
- 不限制思考次数；连续两次提交错误后轻亮帮助按钮，不强制弹出答案。
- 没有语音时用手势动画和短句解释操作；图标旁仍有明确文字。

### 3.4 并行攻击节奏

- 弹弓手独立以 0.8 秒间隔攻击；投石手以 3 秒间隔攻击。新弹药解锁后具备目标的射手可立即发出首发。
- 弹药不限发数，学习、切换题目和种植伙伴不会暂停其他射手。
- 保留每个射手的资源成本、种植冷却、生命和射程约束，多买伙伴增加输出。
- 旧存档中的有限弹夹不再驱动攻击；缺少共享弹药字段的旧检查点按空弹药库读取。

## 5. 首发知识库与关卡

### 5.1 知识分级

不绑定教材，所有等级是产品内部等级。汉字层级以常用程度、生活熟悉度、构字关系、读音和意义难度综合排序；300/800/1600/2500/3000/3500 为远期累计规模规划，不表示当前已整理或有精确等级字表。

- H1–H6：逐步扩大常用字范围；H7：熟字新义、文言义和语境运用。
- W1：具体事物动作；W2：常见属性与关系；W3：非透明词义和搭配；W4：书面表达；W5：抽象概念、常用成语；W6：细致语义；W7：专题拓展。
- P1：认部件；P2：简单双拼；P3：独立选调；P4：复韵母/鼻韵母；P5：三拼；P6：整体认读及特殊拼写；P7：连续词语、轻声与语流；P8：语境辨音。层级允许交叉，不要求完成所有前级条目才接触一个后级条目。
- 分别记录汉字、词义与拼音操作能力，不能根据会认字推断会拼读。

声母教学分组：b p m f / d t n l / g k h / j q x / z c s / zh ch sh r；y w 作为教学展示与零声母拼写配套条目。数据同时区分教学标签和音系/拼写角色。

韵母材料分组：a o e i u ü / ai ei ao ou / ie üe er / an en in un ün / ang eng ing ong。完整音节引擎另存介音和拼写规则，不以这张教学表简单字符串连接。

整体认读：zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying。首版未出题的规则也必须显式拒绝，而非生成错误答案。

### 5.2 首发内容：30 字、12 词

这是一份待内容审核的种子清单，不是全量字库。全部核对后标为 reviewed 才可发布。

30 字（仅当前列出的常用义读音）：
马 mǎ、妈 mā、米 mǐ、木 mù、大 dà、土 tǔ、兔 tù、花 huā、瓜 guā、果 guǒ、火 huǒ、山 shān、水 shuǐ、风 fēng、云 yún、雨 yǔ、日 rì、月 yuè、田 tián、牛 niú、鸟 niǎo、鱼 yú、草 cǎo、树 shù、叶 yè、星 xīng、石 shí、门 mén、小 xiǎo、朵 duǒ。

12 词：木马 mù mǎ、小马 xiǎo mǎ、大米 dà mǐ、土地 tǔ dì、花朵 huā duǒ、西瓜 xī guā、水果 shuǐ guǒ、火山 huǒ shān、白云 bái yún、小鸟 xiǎo niǎo、小鱼 xiǎo yú、树叶 shù yè。

词语引入的地、西、白等字作为词内新字记录并展示；30 字是单字任务池，不是整个首发内容的去重字数。前置知识检查按每个词全部音节执行，不能因不在单字池而漏检。

首发使用简单双拼、三拼及已配置的完整音节卡。yún/yǔ/yuè/yú/yè/rì 等涉及特殊规则的内容，使用整体音节卡和提示，不用错误的普通字母拼接。更完整的规则操作留给后续知识包。

## 6. 通关、星星和分数

### 6.1 通关

全部波次已生成完且场上无活敌人、家园爱心>0 即成功；爱心=0 立即失败，停止模拟。同一模拟帧先结算所有伤害/突破，再判结果；家园为 0 时按失败，避免最后敌人死亡与家园死亡竞态。

失败可重试当前波或整关。波次开始保存独立重试快照（waveStart）；离开/后台保存当前进度（checkpoint），包括伙伴、共享弹药、资源、敌人、分数、随机种子等。恢复游戏保留已解锁弹药；失败重试回到波初。未完成拼音草稿仅在本次战斗内保留。重试回滚战斗和分数，不保留失败波所得资源。学习尝试日志不删除，但标记来自重试，避免把重复同题当多场独立掌握。

### 6.2 三颗星

- 守护星：通关。
- 拼读星：通关且≥80%的已完成音节/选字任务首次提交正确并且未揭示答案；有效任务至少 5 个，未达到则不授予。多音节按音节任务计算。计分分母包括所有完成任务，帮助完成也在分母内。
- 策略星：通关且完成关卡表中的唯一目标。

星星各自独立、每关每项只能领取一次；补拿只发未领取项。守护星即解锁下一关，其余星不阻塞剧情。总计最多 15 星。

解锁：开始拥有弹弓手与露珠收集器；过第 1 关获藤编盾卫，过第 2 关获松果投石手；进入新关前先演示新植物。第 5 关奖励“花园守护者”外观徽章与复习模式，首版不引入额外第五植物。

花园星是累计成就点，不消耗；累计 3/6/9/12/15 星分别解锁程序绘制的基地旗帜、边框配色、名牌样式、花园灯光、全章徽章。战斗露珠和花园星完全分开，无购买强度。

### 6.3 得分

完成一个有效音节/选字任务 +100；首次提交正确且未揭示答案额外 +50；普通/护甲/卷轴怪击杀 +50/+100/+200；每波完成 +100；通关剩余每颗爱心 +100。

- 双字词包含两个独立音节任务；整词装弹完成不再重复发 +100。
- 战斗击杀分与学习任务分是不同事件。范围击杀、救援击杀可以获得战斗分，但不得获得知识分。
- 错误无扣分；无速度加分、无连对分数倍率、无语音置信度评分。
- 敌人死亡只结算一次；铲除、卸弹、重开同 taskInstanceId 不产生完成分。
- 最佳分按 levelId + contentPackVersion + difficulty + scoringVersion 保存。不同版本/难度不混排。

## 7. 数据、存档和运行时

### 7.1 数据实体

- CharacterEntry：id、字、义项、读音引用、H 等级、易混字、reviewStatus。
- WordEntry：id、词语、义项、例句、有序音节 ID、W 等级、前置规则、reviewStatus。
- SyllableEntry：id（如 ma3）、无调拼式、带调拼式、tone(1–4/neutral)、教学拆分方案、显示槽、规则标签、audioId|null。
- TaskDefinition：类型 compose/choose_character、内容引用、合法答案签名、候选集、提示、技能标签、兼容武器。
- TaskInstance：唯一 ID、敌人/盾层/音节索引、首次提交结果、帮助级别、提交次数、是否已计分。
- LevelDefinition：波次、敌人、知识池、允许植物、路线、种子、策略目标、前置条件。
- AudioEntry：文件、语音/音效分类、状态 draft/reviewed、文本、读音意图、时长和生成来源。

所有运行时内容以 reviewed 的版本化静态 JSON 发布。内容生成工具可离线辅助，不能让线上模型直接改变答案、伤害、价格或学习完成记录。

### 7.2 拼音引擎规则

采用显式合法音节与教学拆分映射，不能依赖字符串拼接猜读音。标调需覆盖 a/o/e 优先、iu/ui 标后者、i 加调去点、ü 保留或按拼写规则省点。零声母、整体认读、三拼、缩写分别存合法方案；统一 Unicode 规范化避免组合字符比较失败。

词典标调与自然语流发音分字段保存，未来语音不回写标准答案。多音字通过词义/词语 ID 消歧；无语境的多合法答案题要么接受全部合法答案，要么禁止发布。

### 7.3 学习记录

每项内容按操作类型单独统计：见过、提示完成、独立完成、跨关独立完成、隔日再次完成。记录最近时间、尝试数、帮助级别和易错部件；不设置“答对一次=掌握”。首版只展示事实，不输出未经验证的年级诊断。

复习模式初值：50%近期薄弱、30%到期复习、20%已学随机；无适用内容则重分配。未学内容必须通过新内容介绍流程进入，不能突然塞进复习波次。

### 7.4 本地存档

IndexedDB 保存 3 个存档位；schemaVersion 迁移；头像使用现有植物图，不新增角色。波次边界和结算保存检查点，页面后台立即暂停并保存最近检查点引用；首次进入后台也不能继续播放声音。

返回游戏恢复到最近波次起点，界面明确提示“从第 X 波继续”；首版不承诺帧级续玩。存档持久化失败时显示保存失败和重试入口，不能假装已保存。导出 JSON / 导入校验与版本检查；导入覆盖需确认。清空进度在家长入口二次确认。浏览器清理数据的风险在导出页面简明说明。

### 7.5 项目接入

沿用现有 React + Phaser + TypeScript。独立入口建议 `/experiments/pinyin-garden/`，不改动现有 collect/rescue 契约。

建议目录（待创建）：
- `web/src/experiments/pinyin-garden/`：React 外壳、Phaser 场景、输入、音频和展示。
- `shared/src/pinyin-garden/`：纯逻辑拼音规则、schema、战斗/计分可测试模块。
- `shared/content/pinyin-garden/`：版本化审核题库与关卡。
- `web/public/assets/pinyin-garden/`：图片、动画图集、音乐音效。

参考 OpenGame `tower_defense` 的波次、经济、血量/状态架构；单路径、圆形索敌、金币和传统建造逻辑需要改造，不能直接复制即宣称完成。实际复用代码时补充 third-party 来源和许可证记录。

正式代码与内容不依赖 `.workbench/`。资源预加载有进度和可重试错误页；缺学习音频不阻塞进入，缺角色/主战场资源则明确报错，不静默展示空白。

## 8. 动作、音乐与可及性原则

完整资产参见另外两份文档。所有新角色 ID 为 1.1 唯一标准，当前尚未实现，无需保留旧角色 ID 别名。角色动画是反馈，不负责决定伤害是否发生；逻辑事件驱动动画和声音。降低动态效果选项关闭屏幕震动、降低闪光，不改变判定。中文/拼音由代码渲染，禁止让生图模型画知识文字。

首版音乐/音效可用，学习语音开关与喇叭在没有可用语音包时隐藏。后续仅对 reviewed 音频显示试听；音频覆盖不完整时保持无语音玩法，听音模式仅选择有音频的题目。首版不显示不可用的麦克风按钮。

## 9. 验收与实施顺序

### 9.1 必测行为

1. 同行选择、前方目标、穿过不匹配敌人、死亡转移与保留弹药均符合规则。
2. 正确/错误/帮助完成三种路径都可继续游戏，错误不扣资源；帮助暂停。
3. 马 mǎ、瓜 guā、山 shān、鱼 yú、月 yuè、牛 niú、风 fēng 与双字词有正确显示和适用槽；非法组合被拒绝。
4. 范围击杀和救援不虚增学习记录；取消/重装/重试不刷分；任务首次奖励幂等。
5. 每关从起始解锁状态可通关，不依赖尚未获得的植物、音节或语音。
6. 三行同时有敌人时字牌不遮挡装弹区；实际平板能点击所有部件，拖拽禁用也可通关。
7. 切后台暂停；刷新恢复波次起点；三存档隔离；损坏导入不会覆盖现有存档。
8. 关卡失败、波次重试、全关重开、最后敌人/家园同帧死亡结果稳定。
9. 音乐/音效/学习语音分别控制音量；首版不存在学习语音空请求。
10. 全部角色动画无脚底跳动、翻向错误、缺帧、弹袋/托篮发射锚点错位；透明背景真实有效。

### 9.2 验证方式

- 纯逻辑单元测试：拼音合法映射、标调、计分、星星、快照与任务去重。
- 浏览器集成验证：完成 5 关流程，错误与帮助路径，暂停/刷新/导入导出。
- 平板实机试玩：观察误触、找不到目标、是否理解帮助，记录学习困难与 UI 困难，分开处理。
- 性能目标：目标设备实际战斗不持续低于 30fps，努力稳定 60fps；测量真实资源包大小与首屏加载时间后优化，不凭规格宣称达标。
- 仓库检查：type-check、生产 build、受改动影响的测试；不因文档改动本身运行全仓测试。

### 9.3 交付顺序

A. 固定数据契约和首发题库审核 → B. 完整制作 7 角色/2 背景及全部动作 → C. 战斗/装弹/帮助闭环 → D. 五关/奖励/存档 → E. 音乐音效与完整视觉接入 → F. 实机试玩调整。

为保证风格，素材可以先确认一张角色参考再批量制作，但最终交付必须覆盖全部首版资产，不止样片。学习语音是独立后续批次，不阻塞 A–F。

### 共享规则实现版本

最高分使用 `shared-2` 规则键，与旧有限弹夹计分隔离。存档格式向后兼容：旧 Profile 缺少 waveStart、旧战斗状态缺少 sharedAmmo/drafts 时按默认值读取。正式代码不依赖交互稿文件。
