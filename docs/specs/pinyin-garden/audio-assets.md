# 音乐、音效与后续学习语音制作手册

关联：[主 Spec](./spec.md) · 版本 1.1 · 2026-11-05

## 1. 首版与后续边界

**首版生成并接入：4 首音乐、38 类音效（其中 6 类制作 3 个变体，共 50 个音效文件）。首版不生成或依赖学习语音、角色口播、跟读识别。**

后续语音按知识包逐步生成，音频字段可空；无音频不显示喇叭，有审核通过的音频才显示。现有 `.workbench/20261105-pinyin-audio/sample.wav` 是本机合成试听文件，不是教学审核通过的正式资源，不作为游戏依赖。

本文提示词可给支持音乐/音效/中文 TTS 的相应工具使用，不表示当前会话已连接这些服务。不要把音效描述送入普通 TTS；它通常会把描述念出来。按工具的真实能力选择音色、格式、时长和授权设置，不虚构参数。

## 2. 音频统一交付规范

- 保存 WAV 无损源文件；音乐优先 48kHz 立体声，语音/短音效可单声道。最终采样率依工具支持统一转换，不能通过升采样声称提升原始音质。
- 网页交付音乐 MP3 或 AAC；短音效按实际浏览器支持选 MP3/WAV，统一 manifest。保留原始文件但不全部打包进首屏。
- 音乐记录 loopStart/loopEnd；编辑器实际试听首尾，必要时剪辑交叉淡化。提示词“无缝循环”不等于已经无缝。
- 无削波、明显底噪、突兀尾音。音量起始参考：音乐约 -20 至 -18 LUFS、学习语音约 -18 至 -16 LUFS；短促音效以峰值和实机混音评估，不用 LUFS 生硬统一。最终总线真峰值目标≤-1 dBTP。
- 文件命名：`music/{id}.mp3`、`sfx/{id}_01.mp3`、未来 `speech/{pack}/{id}.mp3`。
- 记录提示词、实际输入文本、服务/音色版本、生成时间、时长、循环点、审核状态和来源授权。不得把未经听检的语音标为 reviewed。

音乐只用下文的原创乐器、节奏与情绪描述，不上传其他游戏音轨作参考、不要求仿其旋律或编曲。生成后听检是否出现明显熟悉旋律；发现疑似相似片段时退回重做并保留记录。确认所用服务对预定线上使用的授权条件，不能以免费亲友试玩替代许可。

## 3. 背景音乐：4 条可复制提示词

### M01 `bgm_home` 花园主题，75 秒，循环

```text
生成一段用于原创儿童拼音花园塔防游戏首页的纯器乐背景音乐，约75秒，约90 BPM，轻快、有探索和准备冒险的感觉。卡林巴琴、轻拨弦和柔和钢琴为主，少量轻打击乐，旋律简洁、不过分密集，有稳定舒适的节奏。适合反复循环，开头与结尾和声和节拍衔接，避免明显收尾。没有人声、歌词、说话、哼唱、音效、尖锐高频或突然的大音量变化。原创旋律，不模仿任何现有游戏主题曲。
```

### M02 `bgm_battle` 普通战斗，90 秒，循环

```text
生成原创儿童花园塔防游戏的纯器乐战斗背景音乐，约90秒，约104 BPM，轻快、有持续推进感，种子沙锤、拨弦低音和短小卡林巴琴动机。体现忙碌的布阵与射击，但保留思考空间，旋律重复清楚而不抢注意力。开头与结尾适合无缝循环，没有大片式高潮，没有人声、歌词、哼唱、武器声或突然重击。与温暖花园主题同一音乐世界，非恐怖。
```

### M03 `bgm_final_wave` 最后一波，75 秒，循环

```text
生成原创儿童花园塔防游戏最后一波战斗的纯器乐音乐，约75秒，约112 BPM。延续卡林巴琴、拨弦低音与种子沙锤，增加轻鼓节奏与短促弦乐，营造“卷轴怪来了，一起守住花园”的兴奋感。紧张但友好，避免压迫、警报、尖叫、巨大低频或恐怖音色。没有人声和歌词，适合循环，结尾与开头自然连接。
```

### M04 `bgm_result` 通关结算，20 秒，不循环

```text
生成原创儿童花园塔防通关后的纯器乐结算音乐，约20秒。前两秒有清楚、温暖的小庆祝乐句，随后用卡林巴琴、轻拨弦和柔和钢琴平稳展开，表达努力后守住家园的喜悦，结尾自然收束。没有人声、歌词、掌声、对白或夸张号角，音量平稳，不复制现有游戏旋律。
```

主页/普通/最后一波切换交叉淡化 0.8–1.2 秒；结算仅播放一遍，之后低音量主页音乐或安静。失败只用短音效，不循环悲伤音乐。暂停将音乐降低并停止战斗音效；进入后台全部暂停。

## 5. 混音与播放调度

- 总线：Music / SFX / Speech，独立音量，首版隐藏未有内容的 Speech 控件。
- 同一音效最短重播间隔约 80ms；短音效总并发上限 8，移动触地声最多 2；优先保留发射、命中和危险提示。
- `danger` 每次危险状态进入播放，持续危险最多每 8 秒一次；不要每帧提醒。
- 组合正确音效仅在任务首次从未完成变为完成时播；计分重放不触发。
- 胜利短音效与结算音乐前奏择一突出，降低另一项；不要同时最大音量播放。
- 浏览器首次用户点击后初始化音频上下文，阻止自动播放时保留可点击开启按钮，不报假故障。
- 静音不影响操作和通关；声音信息都有视觉对应。
- 未来 Speech 播放时 Music 降约 8–12dB，SFX 降约 4–6dB；语音结束平滑恢复。

## 6. 后续学习语音：清单与提示词

不要求家长自行录音；使用支持普通话与发音控制的 TTS/音频模型生成，保存为静态文件。基础拼音更需要听检。普通 TTS 不支持的独立音素任务不能靠裸字母蒙混；保留缺失状态直到有可靠产物。

### 6.1 分批补齐

| 批次 | 内容 | 输出规模算法 |
|---|---|---|
| A | 首发目标带调音节 | 从 30 字和 12 词中提取带调音节去重，每音节一文件；先补最常玩的条目 |
| B | 四声对比 | 选适合的同音节四声组，每个带调音节一文件，不为没有必要的组合强造词 |
| C | 12 个首发词语 | 每词一个自然整词录音 |
| D | 声母、韵母教学示范 | 每个教学条目一文件，区分呼读音/拼读示范，审核口径一致 |
| E | 16 条引导 | 每条独立文件，见下表 |
| F | 后续知识包 | 新增条目与既有音频去重，只生成缺失部分 |

同音同调可共用独立音节声音，但词语必须按整词处理。语音可共享不意味着文字或词义 ID 合并。

### 6.2 通用声音风格提示词

适用于允许额外风格指令的生成工具。若工具只有“朗读文本”输入框，只输入目标文本，风格通过工具设置实现，不要把整段指令放进朗读正文。

```text
请用清晰、自然、亲切的成年普通话女声生成教学语音，音色稳定，不模仿儿童，不夸张卖萌，不加入角色变声。发音准确，节奏略慢但保持自然，不唱读，不加音乐、音效、混响或其他声音。只读指定正文，不读提示词、文件名、标点名称或解释。保留自然句尾，避免截断。相同批次保持音色与响度一致。
```

### 6.3 独立带调音节示例

文件 `syllable_ma3.mp3`；朗读正文 `马`；结构化发音意图 `mǎ / ma3`。

```text
这是独立音节的拼音示范。只读一次汉字“马”，读音 mǎ，第三声。以孤立音节教学示范方式清楚体现三声，语速稍慢但不拖长唱读。不读“第三声”“拼音”“马字”或任何解释，不加入其他字。无背景声音。
```

四声组分别单独生成：`妈 mā / 麻 má / 马 mǎ / 骂 mà`。显示内容与音频意图分开存储；不能仅输入 `ma3` 并假定模型会按拼音读。

### 6.4 声母与韵母示例

```text

```

```text
生成汉语拼音韵母 ang 的独立教学示范。清楚体现后鼻韵母，不读英文字母 A N G，不增加声母，不说“韵母ang”。只输出一次声音，保持自然教学语速，无背景。
```

上述是生成意图，不保证所有服务能执行。若服务把 m 读成字母名、ang 读成外语或额外加入声母，判定失败。声母呼读音与本音须由审核口径明确，不能直接裁剪完整汉字语音来冒充标准声母教学音。

### 6.5 整词示例

文件 `word_huaduo.mp3`；正文 `花朵`。

```text
只自然朗读词语“花朵”，普通话读音 huā duǒ，清楚、略慢，但保持完整词语的自然连贯性。不要逐字解释，不读拼音字母，不把两个单字录音机械拼接，不加背景声音。
```

后续轻声示例正文 `妈妈`，自然读 mā ma，第二个音节轻声；变调示例正文 `你好`，按自然普通话连读处理，文字标注仍由知识库保存规范拼音。词典音调与实际语流记录分别审核，不互相覆盖。

## 7. 语音数据与审核

每条记录：id、displayText、spokenText、pronunciationIntent、type、voiceId、sourceVersion、file、durationMs、reviewStatus、reviewNotes。

- draft：已生成未听检；reviewed：确认发音与用途；rejected：错误需重做。
- 试听验收页面同时显示字/词、规范拼音、预期发音、播放/重播、通过/拒绝。
- 单音节重点核对声调和音节；词语重点核对多音字、轻声、变调和自然度；引导重点核对是否多说文字、是否与 UI 一致。
- 合成成功、文件非空、语音识别转写相同都不足以证明教学发音正确。必须听检，不承诺自动生成即可全部正确。
- 单个文件失败不影响其他已通过文件。已发布包只包含 reviewed 文件。
- 当前首版不加载该语音库；后续首次启用按真实覆盖率开放内容。

## 8. 音频验收

检查首尾无截断、背景干净、音量一致；循环音乐接缝实际播放至少三轮；同时发射/爆炸/危险提示时不盖住未来语音；平板扬声器和耳机均试听；切后台、静音、重开关卡后没有残留声音。

正式音频归档进项目资源目录；未选音色与生成失败文件留在当次工作目录，可在复核后清理。不得将 API 密钥放入前端；后续批量合成在受控的离线工具或服务端执行，浏览器只读取静态音频。
