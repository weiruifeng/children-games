### 执行原则

- 每个任务完成：实现 → 该任务针对性验证 → 更新复选框与证据。只有阶段门通过才进入依赖它的阶段。
- 代码中间阶段可用明确标识的几何调试图验证逻辑，不能拿它替代最终原创素材。
- 素材工作流和代码可在进度上交错推进；本计划不要求启动子代理。单个执行者遇到生成等待时可做独立编码任务。
- 生成素材调用按相应工具真实能力执行；音乐工具/授权不可用时，记录具体缺口并继续可执行任务。不能用静音或现有商业素材冒充完整音频交付。
- 不生成学习语音、不接入跟读识别；后续音频接口留空即可。
- 不新增真实儿童姓名、账号、云端行为上传或广告统计。试玩记录使用本地存档与家长主动导出。
- 一次性截图、探针、生成候选、验收日志集中在 `.workbench/<时间>-pinyin-garden/`，遵守 temp-artifact-hygiene；正式源代码、测试、资源与本计划不依赖该目录。
