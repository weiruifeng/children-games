# 图片与动画素材维护规范

关联：[玩法规则](spec.md)。正式原图位于 `web/public/assets/pinyin-garden/`，映射见 `assets/manifest.ts`；生成源文件保留，未选候选和截图进入 .workbench。历史逐项生成需求通过 Git 追溯。

## 美术风格

角色与道具保持明亮卡通、圆润轮廓、柔和哑光材质、温暖左上光源及统一视角。透明素材保持真实 alpha、完整主体和裁切余量，不烘焙文字、字牌、弹药、阴影或特效。文字与界面由代码绘制。背景不包含容易误认成露珠、字牌或弹药的装饰。造型与素材来源须有明确授权。

## 动作与图集规范

更换或扩展角色时保持以下动作覆盖。帧数是目标交付规格，可用关键帧和程序补间实现，但必须得到完整可播放结果。待机通常复用定稿加程序变形，不强制重复生图。

| 角色 | 状态/目标帧数 | 动作要点 |
|---|---|---|
| 豆荚弹弓手 | idle(程序)、load(3)、ready(2)、fire(5)、hit(2)、exit(4) | 枝架轻摆；弹袋接种子；拉弦；藤索释放回弹；枝架弯曲受击；枝杈合拢 |
| 露珠收集器 | idle(程序)、produce(6)、hit(2)、exit(4) | 漏斗叶舒展→杯体倾斜排珠→恢复；卷叶收拢；叶杯闭合 |
| 藤编盾卫 | idle(程序)、hit(3)、exit(5) | 编织面受力绷紧再恢复；藤条松开盘成一束；损伤层持续 |
| 松果投石手 | idle(程序)、load(3)、ready(3)、fire(6)、hit(2)、exit(4) | 托篮承重；弯枝后拉；向前上方挥臂抛射；树桩短震；投臂收拢 |
| 墨团怪 | walk(8)、attack(6)、hit(2)、exit(6) | 压缩弹跳，朝左；身体前伸撞击；被压扁回弹；缩成墨点消散 |
| 纸壳墨团怪 | walk(8)、attack(6)、hit(2)、armor_break(5)、exit(6) | 包纸墨团低跳；纸壳震动；纸片展开脱落；破甲切墨团基础身体 |
| 卷轴怪 | walk(8)、attack(6)、hit(2)、shield_break(4)、exit(6) | 两端纸卷交替滚动；纸页展开拍击；折边松开；卷成小纸筒退场 |

合计 129 个非待机帧位置（含角色外观变体），不意味着需要 129 次独立生成。推荐每状态生成一行或分小批关键帧；动作表全覆盖才算完成。

每帧交付 256×256 透明 PNG；图集每行最多 8 帧、最大边长 2048px。基准落地线 y=224，水平锚点 x=128；角色全身位于约 x=32–224、y=24–224。素材规范化时保留原比例，不能为了凑画布拉伸身体。按角色记录发射锚点/受击中心/字牌锚点；发射锚点可按帧覆盖，不能固定一个不随动作变化的发射点。

建议帧率：行走 8–10fps，发射 12–16fps，受击 12fps；具体时长按主 spec 与动作意图调节。缩放/旋转的程序补间不能让根节点偏离格子或落地线。


## 交互与程序反馈

按钮按压、地图与卡片选中、弹层、拼音逐部件示范、装弹、种植、露珠收集、攻击、受击与胜负均提供对应反馈。动画不遮挡汉字和拼音，不参与判题或战斗计时。系统或游戏内减少动态效果启用时简化动画，保留颜色、图标或文字反馈；不恢复已移除的风铃自动救援。

## 素材验收

1. 每角色运行全部动作，检查基线、锚点、方向、身份一致、帧数、透明边缘与尺寸。
2. 放入真实 3×6 战场，缩至实际尺寸检查字牌、部件可读性和遮挡。
3. 背景受保护元素检查：无角色/露珠/弹药或近似误导装饰。
4. 发布前核对最终造型、背景和界面是否形成独立视觉表达，不能把“换色”或提示词中写“原创”当作审核通过依据。
5. 资源清单记录 id、源文件、最终文件、宽高、动画帧/时长、锚点、提示词、参考图、版本与审核状态。

透明背景需同时启用生成工具相应选项。生成后存在错误时明确标记待修，不以“AI生成就是如此”作为验收理由。
