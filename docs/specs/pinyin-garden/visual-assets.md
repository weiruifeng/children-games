# 图片与动画资产制作手册

关联：[主 Spec](./spec.md) · 版本 1.1 · 2026-11-05

## 1. 生成方法和数量

首版交付：7 个角色定稿、2 张背景、7 套完整角色动画、2 个藤编盾卫损伤层、1 个护甲配件层、5 个独立道具图。角色定稿用于制作参考；运行时可以复用动画首帧，不重复下载定稿图。

- 需要生图：角色造型、背景、动作关键帧、道具。
- 程序制作：文字/拼音/声调、字牌、护盾轮廓、槽位、候选卡、星星/爱心、徽章、进度条、影子、粒子、炮弹轨迹、装弹飞行动画。不要让 AI 画字。
- UI 使用代码/SVG 生成，适配字号与点击区域。植物卡缩略图直接来自定稿，不额外生成另一套角色。
- 所有图片均按本项目独立造型制作。不要使用未经授权的商业游戏截图或角色图作生成参考，不以其名称作为提示词模仿对象；只引用本项目已确定的原创定稿。

保存建议：角色 `characters/{id}/`，背景 `backgrounds/`，道具 `props/`，图集 `atlases/`，相对根为 `web/public/assets/pinyin-garden/`。

生成源文件保留；未选候选和验收截图放当次 `.workbench/<时间>-pinyin-art/`。正式资源不依赖该目录。

## 2. 统一美术提示词（角色、配件、道具每次都附加）

复制“统一提示词 + 对应资产专用提示词”作为一次完整请求。一张角色参考审核后，后续每次附上该参考并说明只参考风格或保持身份，不把多张角色挤到同一张图中。

```text
为原创儿童拼音塔防游戏《拼音花园保卫战》制作可直接用于游戏的二维角色或道具素材。明亮卡通、轻微立体体积感、干净圆润的轮廓，细节克制，既可爱又有战斗动作的力量感。统一温暖日光，左上方光源，中等粗细深色轮廓；材质为柔和哑光插画，不做照片写实或高反光塑料。侧面略带四分之三视角，适合横向路线塔防。主体完整居中，四周留至少 12% 透明余量，轮廓缩小后仍清楚。真实透明 alpha 背景，无地面、无烘焙投影、无背景色卡、无棋盘格。没有文字、拼音、数字、logo、水印、界面或额外角色。不同角色保持同一画风、视角、光源和轮廓粗细。
```

建议角色定稿生成 1024×1024 PNG，保持透明；实际交付尺寸可以后处理规范化。工具不能精确输出要求尺寸时，先生成再裁切/缩放，不宣称提示词可保证像素对齐。

## 3. 七个角色逐项生成提示词

每段与上方统一提示词合并。先生成静止中立姿态，之后所有动作必须附上该角色定稿作为身份参考。

```text
原创花园伙伴，朝画面右侧。身体是一株矮小的 Y 形浅木色枝架，两条分叉之间连接深绿色弹性藤索，藤索中央有一个豆荚形弹袋。两只琥珀色小眼睛位于枝架交叉点下方，底部三条短根须支撑，侧面一片不对称小叶。轮廓主要是清楚的 Y 形，弹袋与藤索可独立移动。中立姿态，藤索轻度绷紧。发射靠拉弦和释放，不设置嘴部炮口、圆管、巨大球形头部。单个完整角色，无弹药、字牌、特效、文字或背景。
```

## 4. 背景逐项生成提示词

背景为不透明图。目标 2048×1280（16:10）；若工具提供其他比例，预留裁切并最终规范为此尺寸。以 1280×800 逻辑布局检查，不仅看原图好不好看。

### B01 `bg_battle_day` 白天战场

```text
为原创儿童拼音塔防游戏制作 16:10 横向花园战场背景。明亮卡通插画，柔和哑光体积感，左上暖日光，色彩清爽，统一中等粗细轮廓。轻微俯视的草地平面，能够承载朝右植物和朝左敌人的侧面角色。画面中央偏下约横向 17%–88%、纵向 21%–74% 是宽阔、平整、低对比、细节很少的绿色草地，供程序叠加三行六列棋盘，不画网格。场景是一座溪谷中的纸艺苗圃，左侧边缘为纸折拱亭与苗圃出口，右侧边缘为通向溪谷的圆石入口；远处溪流、层叠纸艺山坡和淡云只用于顶部边缘框景，底部留干净区域承载操作界面。
禁止出现豆荚弹弓手、露珠收集器、藤编盾卫、松果投石手、墨团怪、纸壳墨团怪、卷轴怪、种子弹、松果、独立青蓝水滴、发光金币、字牌、盾牌、风铃装置以及近似装饰物。不要在背景上画可互动对象，不画按钮、卡片、文字、字母、数字、logo、水印。视觉焦点必须留给之后叠加的角色与文字。
```

```text
为同一原创儿童拼音塔防游戏制作 16:10 横向花园基地背景，匹配战场参考图的光线、轮廓和哑光卡通画风。温暖晴天的溪谷纸艺温室，边缘有折纸拱架、苗圃木台、远处浅色山坡和溪流。中央是宽阔安静的苔绿空地与浅色小径，中央上半部留白放标题与开始按钮，右下留白放角色收藏展示，左下留白放设置入口。画面有欢迎回家的感觉但不拥挤。

```

| `projectile_seed` | 单颗扁椭圆青绿色种子，浅金色接缝，向右的中立外观，无面部、字母、尾迹、背景或投影。 |

## 6. 全角色动作清单

首版所有行均要完成。帧数是目标交付规格，可用关键帧和程序补间实现，但必须得到完整可播放结果。待机通常复用定稿加程序变形，不强制重复生图。

| 角色 | 状态/目标帧数 | 动作要点 |
|---|---|---|
| 豆荚弹弓手 | idle(程序)、load(3)、ready(2)、fire(5)、hit(2)、exit(4) | 枝架轻摆；弹袋接种子；拉弦；藤索释放回弹；枝架弯曲受击；枝杈合拢 |
| 露珠收集器 | idle(程序)、produce(6)、hit(2)、exit(4) | 漏斗叶舒展→杯体倾斜排珠→恢复；卷叶收拢；叶杯闭合 |
| 藤编盾卫 | idle(程序)、hit(3)、exit(5) | 编织面受力绷紧再恢复；藤条松开盘成一束；损伤层持续 |
| 松果投石手 | idle(程序)、load(3)、ready(3)、fire(6)、hit(2)、exit(4) | 托篮承重；弯枝后拉；向前上方挥臂抛射；树桩短震；投臂收拢 |
| 墨团怪 | walk(8)、attack(6)、hit(2)、exit(6) | 压缩弹跳，朝左；身体前伸撞击；被压扁回弹；缩成墨点消散 |
| 纸壳墨团怪 | walk(8)、attack(6)、hit(2)、armor_break(5)、exit(6) | 包纸墨团低跳；纸壳震动；纸片展开脱落；破甲切墨团基础身体 |
| 卷轴怪 | walk(8)、attack(6)、hit(2)、shield_break(4)、exit(6) | 两端纸卷交替滚动；纸页展开拍击；折边松开；卷成小纸筒退场 |

合计 129 个非待机帧位置（含角色外观变体），不意味着需要 129 次独立生成。推荐每状态生成一行或分小批关键帧；动作表全覆盖才算完成。

每帧交付 256×256 透明 PNG；图集每行最多 8 帧、最大边长 2048px。基准落地线 y=224，水平锚点 x=128；角色全身位于约 x=32–224、y=24–224。素材规范化时保留原比例，不能为了凑画布拉伸身体。按角色记录发射锚点/受击中心/字牌锚点；发射锚点可按帧覆盖，不能固定一个不随动作变化的发射点。

建议帧率：行走 8–10fps，发射 12–16fps，受击 12fps；具体时长按主 spec 与动作意图调节。缩放/旋转的程序补间不能让根节点偏离格子或落地线。

## 7. 动画生成提示词模板

必须附角色定稿；字段替换来自上表。每次只生成一个角色的一种动作，避免多动作混排。下方模板加动作脚本就是完整请求。

```text
参考图是已经确定的角色身份。为同一角色生成游戏二维逐帧动画，动作【动作名】，共【N】帧，从左到右等宽排列成一行。保持面部、材质纹理、颜色、配件数量、比例、轮廓粗细、视角、光源完全一致，方向保持【植物朝右/敌人朝左】。每个格子均完整显示角色，透明背景，中立落地基线一致；墨团弹跳允许身体离地，但根节点保持一致、起落点一致，帧之间留足透明间隔，不越格。
动作顺序：【粘贴对应脚本】。
仅角色自身运动，不画弹药、文字、汉字牌、光晕、烟雾、阴影、地面、网格线、帧编号、logo 或水印。循环动作末帧应自然衔接首帧，但不以完全复制首帧代替末帧。非循环动作清楚结束于恢复姿态或退场姿态。
```

动作脚本（对应所有状态）：

- `load` 三帧：弹袋/托篮打开 → 接收看不见的弹药并轻下沉 → 稳定承重；不把实际种子/松果烘焙进帧。
- 弹弓 `ready` 两帧：藤索向左后拉至中度 → 拉至准备释放的紧绷状态。
- 弹弓 `fire` 五帧：拉弦 → 最大拉伸 → 释放瞬间 → 藤索向前回弹 → 中立；没有鼓嘴或气压喷射。
- 收集器 `produce` 六帧：卷叶半开 → 叶片展开 → 叶杯承接 → 叶杯向右倾斜 → 回正 → 叶片半开；水滴由程序生成。
- 藤盾 `hit` 三帧：编织面后弯绷紧 → 藤条回弹 → 中立，底部根须不滑动。
- 投石手 `ready` 三帧：托篮承重 → 枝臂向后弯曲 → 稳定瞄准，根部不移动。
- 投石手 `fire` 六帧：后拉 → 最大弯曲 → 向前上方挥臂 → 放出投射物的姿态 → 枝臂回弹 → 中立，弹药由程序绘制。
- 墨团类 `walk` 八帧：落地压缩 → 蓄力压低 → 伸长起跳 → 升起 → 顶点 → 下落 → 接触地面 → 压缩回弹。无脚和鞋；纸壳版护甲随形但不融进身体。
- 墨团类 `attack` 六帧：落地站稳 → 后缩 → 身体向左拉长 → 前端接触 → 收回 → 中立。
- 卷轴怪 `walk` 八帧：左卷承重 → 纸面略展开 → 右卷滚动 → 重心转移 → 右卷承重 → 纸面回卷 → 左卷滚动 → 中立；根节点平移由程序处理。
- 卷轴怪 `attack` 六帧：收紧 → 左侧纸页展开 → 伸出 → 纸页拍击 → 卷回 → 中立。
- 通用 `hit` 两帧：按材质受力（枝条弯曲/墨团压扁/纸卷收紧）→ 恢复，不新增肢体或移动根节点。
- 藤盾 `exit` 五帧：摇晃 → 编织松开 → 藤条盘曲 → 收束 → 小藤束，透明渐隐由程序完成。
- 其他伙伴 `exit` 四帧：支架或叶片收拢 → 下沉 → 闭合 → 小轮廓；不画土坑或背景。
- 墨团类 `exit` 六帧：失衡 → 压扁 → 回弹缩小 → 墨尖收回 → 小墨滴 → 更小墨点；纸壳先松开，不出现人形倒地动作。
- 卷轴怪 `exit` 六帧：晃动 → 展开 → 两端回卷 → 墨芯收拢 → 小纸卷 → 更小纸卷。
