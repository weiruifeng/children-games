- 账号隔离的IndexedDB仓库、冻结inFlight、事件outbox、同步恢复日志、Web Locks/租约、重试、冲突比较和归档选择、旧档迁移receipt、NDJSON备份。

## 容量实测

45,000条合法学习事件，无归档截断：

- 真实Chromium写入IndexedDB约1,150～1,239ms；200条/批，共225批，同步到本机MySQL约8,274～8,687ms；服务端summary确认45,000条，状态synced。
- 浏览器完整备份11,656,193字节；数据含事件ID及独立schema版本。热快照不携带全部attempts。
- 确定性仓库测试完成导出后导入另一槽，45,000条全部保留；样本备份11,476,152字节、热快照389字节，往返约15～17秒（fake-indexeddb与mock传输，不能当网络性能）。
- 服务端永久事件不按45,000条截断。这是本次测试样本数，不是承诺任意设备可容纳无限本地历史。

未将本机数值当作生产SLA。所选槽仍缓存完整事件；128MiB文件指纹需要文件缓冲区，大归档也占用额外内存，真实iPad上限和长时间运行需实测。
