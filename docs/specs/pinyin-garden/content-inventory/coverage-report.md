- 原1294读音、1110基准项、1420录音文件记录全部保留；关卡目标无漏项无重复，每关最多6项。

- 运行游戏未改变；内容草案的候选筛选与关卡分配均已更新。接入时需在出题、复习和干扰项三处同时执行分组约束。
