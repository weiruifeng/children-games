## 如何筛选

1. 以《通用规范汉字表》2013年一级3500字为常用字集。二、三级字或集外字移入挑战池。
2. 常用字的罕见读法不能自动进入主线。具体读音还要有常用读音映射、频率字音词典，或教学字音和词语语境的交叉证据。
3. 重新检索完整字库中的3500字，不只检查旧版每音前4个候选。有其他合格常用字，就换字保留读音；确实没有，才整项转入挑战。
4. 有常用承载字且有音频 → 主线；有常用字但缺音频 → 常用字补充；没有合格常用字 → 挑战附加，不受录音有无影响。
5. 主线的题干、复习和干扰项都不得混入挑战字。同音的非常用字保存在challengeCandidates，仅供自选挑战，不额外计为必须完成的新读音。
6. 关卡全开放，挑战自选，不影响主线完成。总覆盖仍包含挑战读音，不能把主线完成标成“全部读音已学会”。

摘出旧候选字音对 **1731** 项，涉及 **1362** 个不同非常用字；**152** 项读音整项转挑战，**26** 项重新选择首选字。1294项读音全部保留。

**常用不等于小朋友已经认识。**3500字是客观第一层筛选，不是低龄熟悉字清单。优先选择米、马、猫、笔等熟悉例字；剩余词义、语境、适龄性与发音仍需审校。程序筛选不伪称人工审核。

## 分组依据

- [教育部对2013字表的说明](https://www.moe.gov.cn/jyb_xwfb/s271/202009/t20200915_488073.html)：一级3500字为常用字集。
- [一级字表机器转录来源](https://github.com/lqfeng/ChineseCharacters)：核对3500个唯一字与连续序号，仅使用成员关系；[来源许可证Apache-2.0](https://github.com/lqfeng/ChineseCharacters/blob/master/LICENSE)。筛选输入与SHA-256记录在common-character-policy.json。
- 标准字集不能单独证明某个读音常用，所以上面另设具体读音证据条件。

## 来源与可信程度


- [GF0025-2021 官方PDF](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202103/W020210329527301787356.pdf)：教学音节核对基准；面向国际中文教育，不作为小学课序，也不宣称等于全部普通话字典读音。
- [标准查询转录](https://dict.sinologyinstitute.com/)：取得1110项音节、例字和可匹配的词语语境；对照原文样本与数量，仍需逐项人工审校。只保留字音等事实及候选，未复制网站程序到交付物。
- [标准英文预览](https://wuzhou.hfbook.cn/api/wzsc/arc/arc/file/CA1635406039455178/81630125/AT1665387053573178.pdf)：交叉核对一级前100项，全数相符。该预览仅15页，未当作完整标准。
- [pinyin-data 0.16.0](https://github.com/mozillazg/pinyin-data)：字音映射、规范字常用读音与频率词典候选。保留[MIT许可证](pinyin-data-LICENSE.txt)。不是所有读音都经过本项目人工审核。
- 本地 `/Users/weiruifeng/ai/PinYinSound`：实际1420个文件，按文件名匹配。未将基础韵母、未知读音或别名强行计成正式汉字题。

下载日期与文件哈希见[source-checksums.json](source-checksums.json)。GitHub提交API未成功返回版本，因此以pinyin.txt自带版本号与内容SHA-256追溯，不编造提交号。
