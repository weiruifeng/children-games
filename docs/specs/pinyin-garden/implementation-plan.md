# 拼音花园：汉字题库与分层课程实施 Plan

版本：2.2 · 日期：2026-11-06 · 对应 [Spec 2.2](spec.md) · 状态：冒险版已实现；最新结果见第9节。

这是对现有游戏的增量改造，不重建攻防系统，也不重做角色、动画或音乐。已确认的产品方向不需要重复询问；候选审核必须留下事实记录，不能批量标记为已审核。用户已授权按Spec实施。下列状态以本轮代码和验收证据为准；试运行子集不等于全量交付。

## 1. 已有输入和实施边界

- 现有14课范围控制、共享弹药、点击发音与v2存档：见 [改造前实现说明](curriculum.md)。
- 候选与分层：见 [整理总览](content-inventory/README.md)、[inventory.json](content-inventory/inventory.json)、[常用字规则](content-inventory/common-character-policy.json)。
- 1124主线、18常用字补充、152挑战，共1294读音候选；193/7/33个读音小关草案，另有6个基础认识关。审核后的数量可调整，必须同步覆盖报告和原因。
- 已做的常用字筛选、页面检查不等于新版游戏完成；既有193项测试等历史结果不可当本版验收。
- 当前 `GardenState.level` 表示战场档位，不得改成新课程编号。旧 `lessonId` 的1–14限制与新增稳定levelId并存处理，不能把数字上限简单改大就算迁移完成。
- `shared` 是纯逻辑；测试由web的Vitest配置同时执行shared与web测试。继续用React、Phaser、TypeScript，不新增游戏引擎或后端依赖。
- `.gitignore` 和当前源码存在既有改动，实施前保存差异基线，不覆盖不相关工作。
- 正式内容、校验器、测试不得读取 `.workbench` 或本机音频绝对路径。一次性脚本、fixture、日志、截图按temp-artifact-hygiene管理，不自动删除旧材料。

## 2. 阶段和依赖

| 阶段 | 任务 | 依赖 | 可检查产物 |
|---|---|---|---|
| 准备 | P0 基线 | 无 | 代码/数据版本、当前行为和未决问题记录 |
| 发布数据 | P1 正式模型与审核流水 | P0 | 可追溯候选→审核→发布模型与差异报告 |
| 拼音与抽题 | P2 拼式/轻声、P3 编排/范围 | P1；P3依赖P2 | 无无解题的正式任务和稳定整局计划 |
| 身份与存档 | P4 记录/迁移 | P1、P3 | v3模型、显式迁移表、失败保护 |
| 界面接入 | P5 汉字工坊、P6 课程入口 | P2–P4 | 原攻防下可玩的三类课程 |
| 音频/完整覆盖 | P7 音频接入、P8 覆盖进度 | P1–P6 | 音频降级、真实覆盖与复习隔离 |
| 验收交付 | P9 全量回归与生产验收 | P1–P8 | 实际验收记录与限制说明 |

实施顺序：P0 → P1 → P2 → P3 → P4 → P5 → P6 → P7 → P8 → P9。先用审核小集合跑通完整链路，再扩到全部已审内容；不能在小集合通过时宣布全量完成。无须引入子代理流程。

## 5. 验证命令和证据

实施阶段先执行基线，修改后运行对应测试；文档更新本身不要求重跑游戏全套测试。

```bash
npm run type-check
npm test -w web -- pinyin-garden
```

最终集成：

```bash
npm test -w web
npm run build
npm run preview -w web -- --host 127.0.0.1
```

预览以实际输出端口为准，访问 `/experiments/pinyin-garden/` 并验证深链接刷新。不能只用开发服务器替代生产验收。新的内容校验器在P1实际创建后，记录真实命令并纳入build/CI；不得在计划中把尚不存在的脚本写成已运行通过。

针对性检查重点：

| 检查 | 失败判定 |
|---|---|
| 内容发布 | draft/excluded进包；语境不明多音字；合法答案缺失；主线混挑战字 |
| 抽题 | 同局换题跳选项；刷新重新抽题；新目标永远不出场；用未学内容补空池 |
| 学习记录 | 看过答案仍算独立；同音共享/AOE/重试刷完成；旧样板成绩升级为独立 |
| 音频 | 无录音发空请求；错误拼式播放；请求失败阻塞作答；过期请求串音 |
| 存档 | 旧数字课号串到新关；迁移失败破坏原档；checkpoint和waveStart混用 |
| 攻防 | 点选强制减速；新增手动发射；改变数值/伙伴权益；词题无可用武器 |

候选资料与迁移fixture只在隔离环境读取，不把正常玩家存档作为测试数据。必要截图和一次性回执归入本轮临时目录，正式测试必须可独立运行。
